漫剧创作工作流

唯一入口：manju-creation-director。发行版本、业务版本与知识版本分别记录；正式分发不表示所有题材或媒体模型都已生产验证。

功能与边界

覆盖原创与小说改编、剧本审查优化、可选清本、资产、导演分镜及视频提示词。按用户指定阶段执行，不自动生图、生成视频或发布。读取被动资料不等于调用其他技能。

如何调用

使用 manju-creation-director（漫剧创作工作流），先读取真实 SKILL.md，核对当前版本，再按我指定的阶段处理。

例如：只做十集大纲；只审查这份剧本，不改稿；按已确认问题优化对白；只规划资产，不生图。找不到真实入口时报告未安装，不改用旧技能。

阶段与旧项目

以用户确认主稿为准，核对路径、版本及哈希，再读取当前阶段必要规则。旧项目保留原文件和绑定；接续时先列迁移映射、保护项和缺失证据，经项目迁移确认后再写新状态。

双端安装与更新

下方下载列表来自已验证发行清单。Codex 与 WorkBuddy 包采用相同业务文件，不为宿主改写创作规则。若只出现撤回的历史版本，新工作流尚未提供可用公开包。

先核对包哈希、真实安装目录及本地差异。包内安装器负责暂存、计划校验、安装和恢复；旧组件退役及外部依赖须单独核查，不自动清理无关技能。安装回执与客户端加载分别验收。

按需运行包内 python workflow_distribution.py check --installed-version <已安装发行号> 查看公开清单。检查不自动安装、不后台轮询；更新须确认，安装后新开聊天核验。

恢复与验证

备份放在技能扫描目录外。中断后保留事务和锁，核对日志后使用 recover --transaction <事务目录> --confirmed。恢复拒绝覆盖后续本地修改。已公开包不覆盖；发布缺陷通过新修订版纠正。文件一致不等于客户端已加载或创作效果已验证。
