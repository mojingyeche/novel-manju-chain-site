01

它能帮你做什么

不是一次性黑箱生成，而是把改编与制作拆成能检查、能确认的阶段。

小说改编

小说先成为完整剧本

先确认时长、风格、平台和改编边界，再按漫剧节奏完成剧本，不额外绕行小说重写版。

剧本修订

问题清单先于改写

检查对白 AI 化、因果、人设、重复、格式、开篇和节奏；只有用户确认的问题才进入修订。

制作交付

冻结后再做资产与分镜

资产状态链与导演规划基于同一份冻结剧本，最终提示词绑定真实资产，不把占位符冒充成品。

02

统一工作流

小说入口与剧本入口最终汇合到同一条生产主链。

  1. 1

    识别输入与目标

    小说或剧本、目标时长、风格、受众平台、不可改内容。

  2. 2

    小说转完整剧本

    仅小说输入执行；完成后与已有剧本进入相同路径。

  3. 3

    只审查，不暗改

    给出位置证据、影响、严重程度和优化方案，等待用户确认。

  4. 4

    定向修订与冻结

    只改获准项目；全量复核后由用户确认冻结版本与哈希。

  5. 5

    资产统筹与导演规划

    从冻结剧本建立资产证据、状态链、视觉方向、调度和镜头设计。

  6. 6

    绑定资产的最终分镜

    检查人物动作、空间、对白对象、口型与跨镜承接后交付。

安装与更新

代码与安装包保存在私有仓库；获授权的使用者需要登录 GitHub。

A

交给 Agent 安装

复制下面的安装指令，发给支持本地文件和 GitHub CLI 的智能体。它应先校验 SHA256，再备份并安装。

B

每次调用先检查新版

Agent 启动时读取公开版本清单。有新版先展示统一更新说明并询问；确认后才安装，安装后停止旧版本流程并要求重新加载。

UPDATE_AVAILABLE → 用户确认 → 安装 → 重新加载

私有下载说明：网站公开不等于安装包公开。未获得私有仓库访问权限时，可以阅读指南，但无法下载 Release。

能力边界
